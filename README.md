# Brent Oil Price Change Point Analysis

## 📊 Project Overview

This project analyzes how major geopolitical events, OPEC decisions, and economic shocks have impacted Brent oil prices from May 20, 1987 to September 30, 2022.

Using Bayesian Change Point Analysis with PyMC, we identify structural breaks in the price time series and quantify the impact of key events.

---

## 🎯 Objectives

1. Identify key events that significantly impacted Brent oil prices
2. Quantify price changes using statistical methods
3. Provide data-driven insights for investment and policy decisions
